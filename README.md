# Arizona Forum Styler

[![Manifest Version](https://img.shields.io/badge/Manifest-V3-orange.svg)](#)
[![License](https://img.shields.io/badge/AGPL_3.0-green.svg)](#)

**Arizona Forum Styler** — это браузерное расширение для Chromium-совместимых браузеров, разработанное для глубокой кастомизации форума Arizona RP на домене `forum.arizona-rp.com`.

Расширение предоставляет десятки готовых визуальных тем, гибкий редактор цветов, настройку фонового изображения или видео, анимированные элементы и набор твиков, превращающих стандартный интерфейс форума в полностью персонализированное пространство.

---

## ⚡ Основные возможности

### 🎨 Готовые темы и визуальные стили
* **80+ встроенных тем:** Тёмные и светлые пресеты на любой вкус — от минималистичных до ярких акцентных, разделённые на категории «Тёмные темы» и «Светлые темы».
* **Избранные темы:** Возможность добавить понравившиеся пресеты в отдельный блок «Избранное» для быстрого доступа.
* **Случайная тема:** Мгновенный выбор случайной темы или полностью случайных настроек через соответствующие кнопки.
* **Темы сообщества:** Доступ к пользовательским темам, публикуемым сообществом проекта, через Discord-сервер.
* **Поиск по темам:** Быстрый фильтр пресетов по названию.
* **Сохранение собственных тем:** Создание, переименование и удаление пользовательских тем во вкладке «Импорт/Экспорт».

### 🖌️ Подробная настройка (Кастомайзер)
* **Палитра цветов:** Точная настройка основного и вторичного акцентных цветов, цвета фона, текста и границ через палитру.
* **Применение акцента к тексту:** Автоматическая подсветка заголовков, ссылок и других элементов выбранным акцентным цветом.
* **Задний фон:** Установка изображения или видео в качестве фона форума, настройка прозрачности, размытия, позиционирования и повторения.
* **Логотип форума:** Замена или скрытие стандартного логотипа, настройка отображения названия сервера.
* **Скрытие элементов:** Гибкое скрытие любых блоков интерфейса — боковых панелей, рекламных блоков, шапок, кнопок и отдельных секций через CSS-селекторы.
* **Анимированные аватары:** Активация плавных анимаций для аватаров пользователей на страницах форума.
* **Настройка навбара:** Закрепление навигационной панели, изменение её прозрачности и цвета.
* **Твики интерфейса:** Скрытие забаненных пользователей, изменение их вида, компактный режим отображения и другие мелкие улучшения внешнего вида.

### 📥 Импорт и Экспорт
* **Экспорт текущей темы:** Сохранение всех настроек в файл или строку для передачи другим пользователям.
* **Импорт темы:** Загрузка ранее экспортированной темы или пользовательской строки настроек.
* **Сохранённые темы:** Управление списком собственных тем — переименование, удаление, быстрое применение.
* **Синхронизация между устройствами:** Перенос тем между браузерами и компьютерами через экспорт/импорт файла.

### 🛠️ Общие инструменты
* **Глобальный переключатель:** Быстрое включение и отключение расширения без удаления настроек.
* **Сообщество проекта:** Прямые ссылки на [Discord-сервер](https://discord.gg/5DbTZzQMWH), [Telegram](https://t.me/arizona_ai_ru) и [обсуждение на Blast.hk](https://www.blast.hk/threads/254740/) для обмена темами, обратной связи и публикации пользовательских пресетов.
* **Локальное хранение:** Все пользовательские настройки и темы сохраняются локально через `chrome.storage.local`.
* **Быстрая загрузка:** Скрипты расширения внедряются на `document_start`, обеспечивая применение стилей до полной отрисовки страницы.

## 📦 Установка расширения

### Из Chrome Web Store (Рекомендуется)
Вы можете установить расширение из официального интернет-магазина Chrome:
*   [Ссылка на Arizona Forum Styler в Chrome Web Store](https://chromewebstore.google.com/detail/gaipajaibkdghopbaflgfjfhfjjgihdg?utm_source=item-share-cb)

### Ручная установка из исходного кода
Если вы хотите собрать или протестировать расширение самостоятельно:

1.  Клонируйте репозиторий или скачайте архив с кодом:
    ```bash
    git clone https://github.com/Arizona-AI/arizona-forum-styler.git
    ```
2.  Откройте браузер Google Chrome (или любой другой на базе Chromium) и перейдите на страницу расширений: `chrome://extensions/`.
3.  Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4.  Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) в левом верхнем углу.
5.  Выберите папку, содержащую файлы проекта (в которой находится `manifest.json`).

## ⚙️ Первичная настройка

1. Перейдите на форум `https://forum.arizona-rp.com/`.
2. Нажмите на иконку расширения на панели инструментов браузера для открытия всплывающего окна (Popup).
3. Во вкладке **«Готовые темы»** выберите подходящий пресет или нажмите «Случайная тема» для быстрого старта.
4. Во вкладке **«Подробная настройка»** скорректируйте цвета, фон, скрытие элементов и акценты под свои предпочтения.
5. Во вкладке **«Импорт/Экспорт»** сохраните итоговую конфигурацию как собственную тему, чтобы в любой момент вернуться к ней.

---

## 🔒 Безопасность и конфиденциальность

* Расширение сохраняет настройки пользователя локально на вашем устройстве с использованием `chrome.storage.local`.
* Расширение запрашивает доступ только к доменам `forum.arizona-rp.com` и связанным сервисам `arizona-ai.ru` / `arizona-ai.tech` для получения информации о пользователях экосистемы.
* Импортируемые пользовательские темы обрабатываются локально и применяются только в рамках текущего профиля браузера.
